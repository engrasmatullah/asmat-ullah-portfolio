# Asmat Ullah — Software Engineer & MERN Stack Developer Portfolio

A professional, recruiter-focused portfolio built around a clean software-engineering identity.

## Positioning
- Software Engineer & MERN Stack Developer
- React, Node.js, Express.js, MongoDB
- REST APIs, authentication, responsive interfaces
- Subtle animation and a focused 3D engineering hero

## Recommended setup

```bash
npm install
npm run dev
```

If the project contains a separate backend, install its dependencies and start it according to its own package.json.

## Before deployment
1. Replace placeholder GitHub, LinkedIn, email and resume links with your real links.
2. Add real project screenshots.
3. Add live demo URLs where available.
4. Check all contact-form environment variables.
5. Test desktop, tablet and mobile layouts.

## Design direction
The portfolio intentionally avoids excessive neon effects, giant 3D objects, particle overload and unnecessary sections. Animation is used to support the content and keep the experience professional.
